📘 Tutorial Belajar Python

1. Apa itu Python?

Python adalah bahasa pemrograman yang sintaksnya relatif mudah dibaca. Program adalah kumpulan instruksi yang dijalankan komputer untuk menyelesaikan tugas.

# Program pertamaku
print("Halo, dunia!")
print("Saya sedang belajar Python")

Ingat: teks ditulis di antara tanda kutip. Tanda # memulai komentar yang tidak dijalankan sebagai perintah.

2. Menampilkan teks dan angka — print()
print("Selamat pagi")
print(9 + 6)
print("Hasil:", 9 + 6)

print() menampilkan informasi. Angka dapat dihitung langsung; teks harus diberi tanda kutip.

3. Variabel dan tipe data
nama = "Ayu"
kelas = 9
nilai = 87.5
hadir = True
print(nama)
print(kelas)
print(nilai)
print(hadir)
TipeContohKeterangan
str"Ayu"Teks
int9Bilangan bulat
float87.5Bilangan desimal
boolTrueBenar atau salah

Nama variabel tidak boleh diawali angka dan peka huruf besar-kecil. Gunakan nama yang bermakna, misalnya jumlah_siswa.

4. Input dari pengguna
nama = input("Siapa namamu? ")
print("Halo,", nama)

input() menerima masukan pengguna sebagai teks. Untuk operasi matematika, ubah teks angka dengan int() atau float().

umur = int(input("Umur: "))
print("Tahun depan umurmu", umur + 1)
5. Operator dasar
OperatorMaknaContoh

6. Percabangan if–elif–else
nilai = 82
if nilai >= 85:
    print("Sangat baik")
elif nilai >= 75:
    print("Baik")
else:
    print("Perlu latihan")

Kondisi menghasilkan True atau False. Tanda titik dua (:) dan indentasi menunjukkan blok perintah.

7. Perulangan for dan while
for nomor in range(1, 6):
    print(nomor)

hitung = 1
while hitung <= 3:
    print("Latihan", hitung)
    hitung = hitung + 1

range(1, 6) menghasilkan 1 sampai 5. Pada while, pastikan kondisi akhirnya menjadi salah agar perulangan berhenti.

8. List dan fungsi sederhana
buah = ["apel", "jeruk", "mangga"]
print(buah[0])

def sapa(nama):
    print("Halo,", nama)

sapa("Dina")

Indeks list dimulai dari 0. Fungsi dibuat dengan kata kunci def untuk mengelompokkan perintah agar dapat digunakan kembali.

🧪 Simulator Perintah Python

Pilih contoh, ubah kode atau nilai, lalu klik Jalankan. Simulator mendukung contoh dasar: print, variabel, operasi matematika, if/elif/else sederhana, dan for dengan range.

Keluaran program akan tampil di sini.

Jika kode belum didukung simulator, baca kembali contoh dan sintaks di tutorial. Simulator tidak menjalankan kode arbitrer, akses berkas, atau koneksi internet.

🚀 Proyek Mini

Proyek 1 — Kartu Perkenalan

Target: gunakan variabel dan print().

nama = "Raka"
kelas = "IX"
hobi = "robotika"
print("Nama:", nama)
print("Kelas:", kelas)
print("Hobi:", hobi)
Proyek 2 — Kalkulator Belanja

Target: variabel dan operator.

harga = 5000
jumlah = 3
total = harga * jumlah
print("Total belanja:", total)
Proyek 3 — Kategori Nilai

Target: percabangan.

nilai = 78
if nilai >= 75:
    print("Tuntas")
else:
    print("Perlu bimbingan")

Tantangan pengembangan

  • Ubah data contoh menjadi data buatan sendiri.
  • Tambahkan minimal dua keluaran yang informatif.
  • Uji program dengan nilai berbeda.
  • Catat satu kesalahan yang ditemukan dan cara memperbaikinya.

📝 LKPD Praktik Python Dasar

Lengkapi identitas, tulis jawaban dan kode praktik. Tombol simpan menyimpan pekerjaan pada perangkat/browser yang sedang digunakan; cetak atau unduh salinan untuk cadangan.

Kegiatan 1 — Output

Buat program yang menampilkan nama, kelas, dan kalimat “Saya siap belajar Python”.

Kegiatan 2 — Variabel dan operasi

Harga satu buku Rp4.000. Hitung harga 5 buku menggunakan variabel.

Kegiatan 3 — Percabangan

Buat program: jika skor minimal 75 tampilkan “Tuntas”; selain itu tampilkan “Latihan lagi”. Uji skor 60 dan 85.

Kegiatan 4 — Refleksi debugging

Temukan atau buat satu kesalahan sintaks sederhana, kemudian tulis cara memperbaikinya.
